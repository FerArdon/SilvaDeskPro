# 🌲 SilvaDesk Pro

**Software de gestión forestal profesional para Honduras.**

Diseñado para ingenieros forestales, regentes y técnicos del sector forestal hondureño.

## ✨ Características
- Gestión de planes de manejo forestal
- Reportes y documentación técnica
- Validación de licencia online con respaldo offline
- Compatible con Windows 10/11

## 📥 Descarga
Ve a la sección [Releases](../../releases) y descarga el instalador `.exe`.
